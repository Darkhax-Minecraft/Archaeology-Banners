<!-- description-start -->
This is the official GitHub repo for the ArchaeologyBanners mod. Adds banner patterns based on Archaeology designs. You can download this mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/archaeology-banners) or [Modrinth](https://modrinth.com/mod/archaeology-banners). Please report issues [here](https://github.com/Darkhax-Minecraft/Archaeology-Banners/issues).
<!-- description-end -->

## Maven Dependency
This project is available on the [BlameJared Maven](https://maven.blamejared.com).

If you are using [Gradle](https://gradle.org) you can add the mod as a dependency by adding the following
to your `build.gradle` file.

```groovy
repositories {
    maven {
        url 'https://maven.blamejared.com'
    }
}

dependencies {
     // NeoForge
     implementation group: 'net.darkhax.archaeologybanners', name: 'archaeologybanners-neoforge-26.2', version: '26.2.0.0'
     // Fabric
     implementation group: 'net.darkhax.archaeologybanners', name: 'archaeologybanners-fabric-26.2', version: '26.2.0.0'
     // Common / MultiLoader / Vanilla / No Loader
     implementation group: 'net.darkhax.archaeologybanners', name: 'archaeologybanners-common-26.2', version: '26.2.0.0'
}
```
